HEALTHCARE APPOINTMENT SYSTEM - FRONTEND

Files:
- index.html  = website structure
- style.css   = complete styling
- script.js   = login/register, doctors, booking and appointment logic

HOW TO RUN:
1. Extract the ZIP.
2. Open the healthcare-appointment-frontend folder in VS Code.
3. Open index.html in your browser.
4. You can also use VS Code Live Server if installed.

IMPORTANT:
This version is a frontend-only college project. Login, users and appointments are stored in browser localStorage. No real server/database is used.
